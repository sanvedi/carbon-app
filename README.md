# Carbon app

Separate React/Vite starter with Convex database, backend and static-hosting configuration, GitHub source control, and the same local Build Sprint skills as build-sprint-app. Convex Auth is the chosen future sign-in system; sign-in and other product features are not built.

Install with npm ci. Run the starter with npm run dev; use npx convex dev separately for backend development. Verify with npm run typecheck and npm run build. Publish only this project with npm run deploy; GitHub pushes do not deploy.

Environment files are ignored. No Prompt Gully keys, data, challenges, scoring or saved progress were copied.
