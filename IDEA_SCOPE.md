# Carbon app scope

Approved 2026-10-08: one page for a shopper to compare two named products by published estimated carbon footprint. Show kg CO2e, exact public source and source figure, and one sentence recommending the lower comparable footprint. If evidence is absent, display "no reliable data for this one". Do not guess. AI runs in a Convex action with OPENAI_API_KEY read only from Convex environment variables. Bound output length. Deploy with npm run deploy and verify two real products on the live page. No sign-in or other features.
